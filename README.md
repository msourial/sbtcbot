# sBTC Bot

A secure Telegram bot for managing sBTC transactions with AI-powered features, focusing on user-friendly wallet management and intelligent transaction processing.

## Key Features

- **Natural Language Understanding**: Communicate with simple phrases like "send money to mom"
- **Biometric Wallet Creation**: Create and access your wallet securely without seed phrases
- **AI-Powered Security Analysis**: Intelligent fraud detection for your transactions
- **Voice Command Support**: Send and receive sBTC using voice messages
- **Intuitive UI**: Clean interface based on Bitcoin Design System principles
- **Real-time Transaction Processing**: Instant updates on your transaction status

## Technology Stack

- TypeScript/React Frontend
- Express.js Backend
- Anthropic Claude AI for natural language processing
- PostgreSQL database for transaction storage
- Telegram Bot API integration

## Getting Started

1. Clone this repository
2. Install dependencies with `npm install`
3. Set up environment variables:
   - `ANTHROPIC_API_KEY`: For AI-powered features
   - `TELEGRAM_BOT_TOKEN`: For Telegram bot functionality
   - Database connection variables
4. Start the development server with `npm run dev`

## Security Features

- Zero-trust verification system
- Continuous biometric authentication
- AI-powered transaction analysis
- No seed phrases to manage or lose
